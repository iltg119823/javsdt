# 按演员浏览本地影片并播放

## 一、已有影片先补演员

1. 保留现有配置 ini。将旧的“【重要须备份】已整理的jsons”缓存放到新 JavSDT 程序文件夹的上一级。
2. 双击 RepairActors.bat，选择整理好的影片目录。它只修改 NFO 演员字段，不重命名、移动视频，也不改封面。
3. 每份修改的 NFO 首次都会保存 `.nfo.before-actors.bak` 备份。
4. 优先使用 JSON 中的演员；缺少时才请求 JavDB。同号分段共用查询和缓存。
5. 网站持续拒绝访问时暂停；保留尚未补齐的文件，稍后重试。程序不会猜测演员。
6. 这一步不是重新整理视频，不需要关闭“跳过已完成影片”。

## 二、Jellyfin 设置

1. 确保极空间的实际影片目录映射进 Jellyfin，例如容器内 /media。
2. 新建“电影”类型媒体库，添加 /media 中实际存放整理后影片的目录。
3. 启用本地 NFO 读取；关闭不需要的在线元数据和图片下载器，避免错误匹配。
4. 对测试影片执行“刷新元数据”；已有记录可选择替换全部元数据，以重新读取 NFO。
   执行前确认在线下载器已经关闭。仅扫描新文件不一定会覆盖原有演员记录。
5. 先测试同一演员的两部影片：打开影片详情，点击演员，确认能看到这两部，再点击播放。
6. 演员关联只涵盖已入库且当前用户有权访问的影片。头像是可选项。
7. 播放取决于 Jellyfin 客户端、视频格式、网络和服务器转码能力；NFO 仅提供资料。

## 三、演员名字与别名

自动统一全角字符、多余空格和完全相同的重复名字，不自动把不同艺名合并。
确需合并时，可在程序目录创建 UTF-8 的“演员别名.json”，例如：

```json
{
  "旧艺名": "希望统一使用的名字"
}
```

再运行 RepairActors.bat。请只填写你确认属于同一人的名字。
已有角色、头像字段会保留。程序不会公开或上传这份别名文件。

## 四、恢复

关闭会写入元数据的播放器或服务，先另存当前 NFO，再用相应的
`.nfo.before-actors.bak` 备份替换原 NFO，去掉备份扩展名即可恢复。
程序没有连接、配置或部署你的 Jellyfin，服务器设置需要你在本机完成。
