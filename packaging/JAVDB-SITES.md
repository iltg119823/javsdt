# JavDB 站点设置与使用

本版将新抓取的元数据集中到 JavDB，不再查询 JavLibrary、JavBus 或 Arzon。

## 更换网址

1. 关闭正在整理的程序，双击 ConfigureSites.bat。
2. 主站默认 https://javdb.com/，备用站默认 https://javdb580.com/。
3. 可修改为你确认可访问的其他 JavDB 站点域名；每行一个备用站。清空备用列表可关闭切换。
4. 点击保存，下次整理或补演员生效，不用重新打包。
5. 设置保存在程序目录 JavDB-Sites.json，优先于旧 ini 的 javdb网址。换版本时一并复制此文件。

也可以直接编辑 UTF-8 JSON：

```json
{
  "primary": "https://javdb.com",
  "backups": ["https://javdb580.com"]
}
```

仅填写站点根地址，不填写影片链接、账号、密码或 Cookie。
代理仍沿用原 ini，例如 HTTP 127.0.0.1:5780；JavDB 代理需设为“是”。

## 备用站规则

连接失败、超时或服务器 500/502/503/504 错误时，按配置顺序尝试备用站。
单轮中记住可用站点，继续请求详情页。每个站点保留原有请求间隔和有限重试。
HTTP 403、429、登录/验证提示页或无法确认的内容不会通过轮换域名继续请求，仍暂停处理。
两个域名可能共享相同的限制，不能保证更换站点后恢复。

## 数据范围

从可访问的 JavDB 页面读取番号、标题、演员、导演、片商、系列、日期、时长、评分、类型，
以及页面确实提供的简介、封面地址。图片可能由 JavDB 页面引用的图片服务器提供。
页面没有提供简介时保持为空，不推断“影片下架”，也不编造简介。
已有缓存、用户修改的 NFO 不会强制覆盖。补演员请使用 RepairActors.bat。
本版没有接入未公开的 App 接口，也未使用或反编译其安装包。
